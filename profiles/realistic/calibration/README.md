# Future hardware recording templates

These files are intentionally empty and have unverified clocks. Replace the
metadata, import actual time-aligned SI samples, and declare tolerances before
running a fit. Keep independent training and held-out recordings. Do not mark
synthetic data as hardware data.

See [the calibration guide](../../../docs/realistic-calibration.md) for every
field, measurement boundary, fitting command and acceptance requirement.
Regenerate with `simhark-calibrate templates OUTPUT_DIRECTORY`.
